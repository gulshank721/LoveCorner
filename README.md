# A little thing for you

An interactive React love-letter experience for a long-distance partner.

## Start it locally

Install a current Node.js LTS release, then run:

```bash
npm install
npm run dev
```

Open the local address Vite prints in the terminal.

## Personalize it

Edit `src/content.js` before sharing it. That file holds the recipient name, the opening questions, memories, and the 10 reasons. Replace or refine any lines with details only the two of you would recognise for the strongest effect.

The final signature and message are in `src/App.jsx`.
